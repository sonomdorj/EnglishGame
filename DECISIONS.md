# DECISIONS

1. The repo had an older skeleton (a different word game). PLAN.md was replaced with "The Name Keeper" spec. Old files `game.js`, `words.js`, `style.css` were removed. `style.css` was written new.
2. Three.js 0.160.0 from jsDelivr via an import map. No addons. Own pointer-lock look code.
3. Port 3010 for `npx serve`. Port 3000 is never used.
4. Browser testing: Playwright with the pre-installed Chromium. The test sandbox blocks the CDN, so tests serve the same three.js file from a local npm copy. The game itself still loads from the CDN.
5. World: 64 x 64 cells, top at y = 0. Collision uses a voxel grid (cell set), not physics meshes.
6. Rendering: one merged mesh with only visible cube faces. The first version (instanced cubes) ran at 1 fps in the software test browser.
7. Houses: 7 x 7 cells, 4 high, stepped roof. Door is 3 wide and 3 high so the player can go inside. 3 houses on each side of a main path. Each villager has one house (h1–h6).
8. Villager families: Oyunaa is Batbayar's daughter (mother Saruul Bold, not a villager). Tsetseg's mother is Enkhjargal. Ganbold Erdene and headmaster Batsaikhan Erdene are brothers (same father, Erdene Damdin). Birthdays are "day-month-year".
9. The player cannot move while a dialog or panel is open. Space only advances dialog then.
10. Quest data (`quests.json`) was generated by a script that uses `dates.js`, so every weekday is computed, not typed. Weekdays were also spot-checked against Python's calendar.
11. A quest's liar is the one whose weekday does not match the real date. Liars alternate between A and B.
12. To answer the weekday question the player needs a calendar. The answer panel shows a calendar that opens at the asked month. The player must find the day and read the column. C opens the calendar any time.
13. Buu's date trap is said in the case announcement (third line). F opens a weekday panel for that date. Correct = "You are right. I am a silly panda." Wrong = "No. Look again." F when nothing is wrong: "I said nothing wrong." Six traps use a villager birthday, so the Family Book can also prove Buu wrong.
14. Words: `quests.json` keeps 3–5 theme words per quest (they appear in the claims). Per Day 4, the words actually taught come from `words.json` at the current level. The quest's word count sets how many.
15. New words are taught in example sentences said by villagers A and B (word in bold), then tested after the penalty in a "Word check": Buu speaks the word, the player clicks the written word from 4 options. No translations anywhere.
16. Adaptive rules count every answer: weekday picks, trap answers and word-check picks. First-try or not does not matter; each wrong click counts as wrong.
17. "Next quest reuses only known words": when there are fewer known words than needed, new words are used.
18. When a level runs out of new words, words come from the next level up, then from lower levels, then known words.
19. Next case starts 5 seconds after "Correct. Next." Talking to Buu (E) repeats the current task or reopens a closed panel.
20. Save (localStorage): quests done, level, streaks, known words, villagers met, items taken, letters read, intro seen. A quest in progress restarts from its beginning after reload. All storage access is in try/catch; a broken save starts a new game.
21. Family Book also lists items taken and letters read (counts, not scores).
22. Night: 4 min day, 2 min night, 8 s dusk fade. Stars at night. Buu says when night starts and ends.
23. Headmaster: visible near the gate in the day. At night he walks a route through the path to each patrolled house door, waits 2 s, and carries a lantern light. Sight: 9 blocks, 50° each side, blocked by walls. Caught: one English line, teleport to the gate, 4 s grace time. He does not catch while a dialog or panel is open.
24. Headmaster adaptive: 3+ catches in the last 5 minutes → speed 2.2 → 1.4 and sight 9 → 5 (back to normal when it drops below 3). 10 minutes with no catch → one more house (max 6), then the 10-minute timer restarts.
25. Letters: one per house, on a table. In the day Buu says "Read it at night. Not now."
26. Pointer lock: Esc frees the mouse and pauses the game with the start screen. Opening a panel frees the mouse without pausing. Big mouse jumps right after lock are ignored (Chrome bug).
27. Buu: walks to 3 blocks from the player, hops when blocked, teleports when stuck 2 s or more than 16 blocks away.
